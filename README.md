HEART ATTACK PREDICTION USING MACHINE LEARNING

PROJECT OVERVIEW

This project aims to predict the possibility of a heart attack using Machine Learning algorithms.

OBJECTIVES
1. Analyze patient health data.
2. Identify important risk factors.
3. Perform data cleaning and preprocessing.
4. Build Machine Learning models.
5. Compare model performance.
6. Predict heart attack risk for new patients.

TOOLS USED
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost

MACHINE LEARNING ALGORITHMS
- Logistic Regression
- KNN
- SVM
- Naive Bayes
- Decision Tree
- Random Forest
- AdaBoost
- Gradient Boosting
- XGBoost

BEST MODEL
AdaBoost
